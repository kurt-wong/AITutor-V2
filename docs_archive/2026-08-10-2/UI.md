## 1. 设计原则

前端遵循 `Docs/Design.md` 的 Apple-like 设计语言，但用途是工具型教育系统，不是营销站。

原则：

- 内容优先，UI 退后。
- 管理后台偏工具型、高密度、可扫描。
- 学生端偏安静、清晰、学习内容突出。
- 单一蓝色强调色。
- 不使用装饰性渐变。
- 阴影只用于需要视觉重量的图片，不用于卡片、按钮和文字。
- 全宽区块通过白色、浅灰、近黑交替形成节奏。

## 2. 设计 Token

### 2.1 颜色

| Token | 值 | 用途 |
|---|---|---|
| primary | #0066cc | 主按钮、链接、焦点 |
| primary-on-dark | #2997ff | 深色区链接 |
| canvas | #ffffff | 主背景 |
| canvas-parchment | #f5f5f7 | 浅灰背景 |
| surface-pearl | #fafafc | 次级按钮 |
| surface-tile-1 | #272729 | 近黑区块 |
| ink | #1d1d1f | 主文字 |
| body-muted | #cccccc | 深色区次要文字 |
| ink-muted-48 | #7a7a7a | 弱化文字 |
| hairline | #e0e0e0 | 细边框 |

### 2.2 字体

- 标题：`SF Pro Display, system-ui, -apple-system, BlinkMacSystemFont, Inter, sans-serif`
- 正文/UI：`SF Pro Text, system-ui, -apple-system, BlinkMacSystemFont, Inter, sans-serif`
- 非 Apple 平台使用 Inter。
- 标题使用 600 weight，正文使用 400 weight。
- 正文建议 17px。
- 标题可以使用负 letter-spacing。

### 2.3 圆角

| Token | 值 | 用途 |
|---|---|---|
| rounded.sm | 8px | 紧凑工具按钮 |
| rounded.lg | 18px | 工具卡片 |
| rounded.pill | 9999px | 主 CTA、搜索、选项胶囊 |

### 2.4 布局

- 结构间距使用 8px 基数的节奏。
- 后台内容区建议最大宽度 1440px。
- 管理后台使用低干扰细边框卡片。
- 学生端使用全宽浅色区块承载主要学习动作。

## 3. 通用组件

### 3.1 顶部导航

- 全局导航：黑色背景、高度 44px。
- 子导航：浅灰背景 + 毛玻璃，高度约 52px。
- 右侧保留主要操作按钮。

### 3.2 按钮

- 主操作：`#0066cc` 胶囊按钮。
- 次级操作：透明背景 + 蓝色边框胶囊。
- 工具操作：紧凑 8px 圆角按钮。
- 按下状态使用 `transform: scale(0.95)`。

### 3.3 卡片

- 工具卡片：白色背景、1px 细边框、18px 圆角、24px padding。
- 图片卡片：图片区域使用 8px 圆角。
- 题目卡片：题干、选项、答案、详解分区清晰。
- 不在卡片内再嵌套卡片。

### 3.4 表单

- 输入框使用胶囊形搜索框或紧凑矩形输入框。
- 标签、错误状态、必填状态要清晰。
- 按钮点击必须有按下反馈。

### 3.5 表格

- 后台表格使用 hairline 分隔。
- 表头使用 caption-strong。
- 行内操作使用蓝色文字链接。
- 筛选区放在内容区顶部。

### 3.6 状态

- 成功：绿色文字或图标。
- 失败：红色文字或图标。
- 处理中：轻量 spinner + 文案。
- 审核中：黄色/琥珀色标签。

## 4. 管理后台页面

入口：`/admin`

### 4.1 登录页

- 居中登录卡。
- 管理员/学生入口区分清晰。
- 表单保持简洁。

### 4.2 工作台

- 顶部摘要卡：待审核数、处理中任务、错题待确认、统计概览。
- 最近任务列表。
- 快捷入口：上传文档、审核队列、AI 组题。

### 4.3 文档上传

- 批量拖拽上传区。
- 显示单文件大小上限和批量上限。
- 上传后显示任务队列和进度。

### 4.4 文档解析状态

- 文档列表，按状态筛选。
- 每行显示文件名、状态、进度、失败原因。
- 支持查看日志和重新解析。

### 4.5 审核队列

- 筛选：文档审核、低置信度题目、生成题、JPG 错题。
- 审核详情页支持编辑内容、答案、详解、配图和元数据。
- 支持通过/驳回。

### 4.6 题库管理

- 多条件筛选：学科、年级、年份、学校、题型、知识点、难度、来源类型。
- 列表显示题干摘要、题型、难度、出现次数、状态。
- 详情页展示完整题目、配图、答案、详解、元数据。
- 支持编辑、删除、合并重复题。

### 4.7 统计分析

- 题型频次与年份趋势。
- 知识点频次与占比。
- 难度分布。
- 错题统计。
- 学生学习趋势。
- 顶部提供自定义时间范围。

### 4.8 AI 组题

- 选择学科、年级、知识点、题型、难度、题量。
- 比例模式：自动 / 手动。
- 显示系统建议比例。
- 生成结果进入审核列表。
- 支持导出学生版和答案详解版。

### 4.9 JPG 错题审核

- 展示上传原图、切分结果。
- 每题显示识别内容和匹配/新建状态。
- 可修改题干、选项、答案、详解。
- 通过后进入错题本。

### 4.10 系统配置

- API Key 掩码管理。
- 模型路由。
- 知识树维护。
- 题型规范维护。
- 审核阈值。

## 5. 学生端页面

入口：`/`

### 5.1 登录页

- 与学生主界面保持同一视觉语言。
- 登录成功后直接进入学习首页。

### 5.2 学习首页

- 顶部：今日建议练习、最近错题、薄弱知识点。
- 核心操作：上传错题、开始练习。
- 保持内容大而清晰，避免信息过载。

### 5.3 错题上传

- 大尺寸 JPG 上传区。
- 上传后显示识别进度。
- 提示“管理员确认后进入错题本”。

### 5.4 错题本

- 列表按时间、学科、知识点筛选。
- 每题显示题干摘要、错题次数、掌握状态。
- 详情页展示解析。
- 支持一键重练、标记已掌握。

### 5.5 练习

- 题目按卡片展示。
- 选择题直接选择。
- 填空题使用输入框。
- 提交后显示对错和解析。

### 5.6 练习结果

- 正确率。
- 每题对错。
- 错误题自动进入错题本提示。
- 薄弱知识点展示。

### 5.7 学习统计

- 错题趋势。
- 知识点掌握度。
- 练习历史。

---

## 6. 禁止事项

- 不使用装饰性渐变。
- 不在卡片、按钮、文字上添加阴影。
- 不引入第二强调色。
- 不把教育工具页面做成营销落地页。
- 不在页面里用文字解释“如何使用”或“功能介绍”。
- 不在卡片内嵌套卡片。
- 不让长题干溢出或遮挡。
